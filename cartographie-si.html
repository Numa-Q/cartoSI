    Aide et raccourcis

    • Cliquer un élément pour le sélectionner, Maj+clic pour en ajouter ; glisser dans le vide pour sélectionner une zone.
    • Glisser pour déplacer ; poignée en bas à droite pour redimensionner ; extrémités d’une flèche déposées sur un bloc : elle s’y attache.
    • Double-clic sur une ligne : édition de son texte dans le panneau de droite.
    • Zone de dessin au clavier : flèches = déplacer (Maj = grand pas), [ / ] = élément précédent/suivant, Entrée = aller aux propriétés, Suppr = supprimer, Échap = désélectionner.
    • Ctrl+Z / Ctrl+Y annuler/rétablir ; Ctrl+D dupliquer ; Ctrl+A tout sélectionner ; Ctrl+molette = zoom.
    • Les modifications sont enregistrées automatiquement dans ce navigateur (IndexedDB). Pensez à « Enregistrer JSON » pour sauvegarder ou partager la carte.
